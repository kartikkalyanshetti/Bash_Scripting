Tricks in Bash: 

bash -n : it shows you that if teh script you ran was run sucessfully or if not shows error on exactly which line
ex: bash -n loop.sh

type "command": gives out which type of command is it like is it builtin etc etc

file "filename": tell the type or content that is in the file like ASCII Text, Bourne again shell, etc

echo $? : Tells the status of previous command execution status
if 0 then the previous command ran successfully
if anything else its failed.
